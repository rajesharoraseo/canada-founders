# CanadaFounders Theme

## Overview
The CanadaFounders theme is designed to support a community of founders and business professionals across Canada. It provides a clean and modern interface for users to connect, learn, and grow their businesses.

## Installation
1. Download the CanadaFounders theme files.
2. Upload the theme to your WordPress installation by placing it in the `wp-content/themes` directory.
3. Activate the theme through the WordPress admin dashboard under Appearance > Themes.

## Usage
Once activated, you can customize the theme settings and import demo content to get started quickly. The theme includes various templates for pages, posts, and custom post types.

### Demo Import
To import demo content:
1. Navigate to the CanadaFounders Demo Import section in the WordPress admin.
2. Click on the "Install Demo Content" button.
3. Follow the prompts to complete the import process.

### Editable Pages
The theme includes several editable demo pages:
- Home
- About CanadaFounders
- Community
- Members Directory
- Events
- Partners
- Funding & Resources
- Founder Stories
- Join the Community
- Contact

Each page can be managed through the WordPress block editor, allowing for easy updates and customization.
