# CanadaFounders Demo Import Plugin

This README file provides documentation for the CanadaFounders Demo Import plugin, which allows users to easily import demo content into their WordPress site using the CanadaFounders theme.

## Overview

The CanadaFounders Demo Import plugin is designed to facilitate the one-click import of demo content, including pages, posts, and custom post types, to help users quickly set up their website with sample data that reflects the theme's design and functionality.

## Features

- One-click demo content import.
- Editable demo pages that match the existing theme design.
- Dynamic content integration for members, events, and partners.
- User-friendly admin interface for managing demo content.

## Installation

1. Upload the `canadafounders-demo-import` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to the CanadaFounders Demo Import settings page in the WordPress admin area.

## Usage

1. On the CanadaFounders Demo Import settings page, read the description of the content that will be imported.
2. Click the **Install Demo Content** button to begin the import process.
3. Monitor the progress indicator during the import.
4. Upon completion, a success or failure message will be displayed.
5. Use the **Reset Demo Content** option to remove content created by the importer if needed.

## Editable Pages

The following demo pages will be created during the import process:

- Home
- About CanadaFounders
- Community
- Members Directory
- Events
- Partners
- Funding & Resources
- Founder Stories
- Join the Community
- Contact

Each page is designed to be easily editable using the WordPress block editor.
